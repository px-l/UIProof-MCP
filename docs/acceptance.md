# 0.1 验收标准

| 能力     | 可核验结果                                                |
| -------- | --------------------------------------------------------- |
| 独立项目 | 单独 Git 仓库、依赖与输出目录；不修改工作台或业务源代码   |
| CLI      | 图片、URL、视口通过 JSON 输入；0/1/2 区分通过、差异、错误 |
| 截图     | 固定 DPR/视口/语言/时区/主题，等待字体图片，连续三帧一致  |
| 对齐     | 默认 1:1，尺寸错误拒绝；显式偏移不忽略暴露边缘            |
| 像素比较 | 同图通过，差异图失败；蒙版分母正确、不能忽略整张页面      |
| 证据     | 每个差异区域有坐标、局部原型/页面/差异图和附近元素        |
| 报告     | 本地 HTML 可查看，错误明确显示；页面文本不能注入 HTML     |
| MCP      | 官方客户端可通过 stdio 启动任务、查询结果、获取问题和图片 |
| 多模态   | 必须显式启用；结构与坐标校验；不覆盖像素结果              |
| Figma    | 锁定文件版本、导入 PNG 与节点；Token 不传给 CDN           |
| 多状态   | 状态有独立动作和基准；互不共享页面状态                    |
| 复验     | 使用原快照；原输入文件改变不影响复验；篡改快照被发现      |
| CI       | 推送和 PR 运行检查与真实浏览器演示，保留报告，无部署动作  |

运行 `npm run check` 查看自动化验证。`npm run demo` 展示缺失卡片、错误数字及错误按钮色的失败报告和修复后的通过报告。

Figma、模型测试使用可控模拟响应，证明适配协议和错误处理，不代表真实账户权限或具体模型效果已经通过验收。真实服务测试需提供对应凭据和设计文件；不应在报告中宣称未经验证的外部能力。
